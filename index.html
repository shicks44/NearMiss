How to play

You have 30 seconds per question. Guess a number or name an item close to the target. If a guess isn’t recognized, try again.

Get closer for more points. An exact hit scores 100. Going over or running out of time scores zero.

Five new daily questions arrive at midnight UTC.

About the numbers

NearMiss uses published figures for strange records, animal facts, food, and other trivia. Estimates with a range specify which figure the game uses.
